# WildRoute Wildlife Asset Sources

The UX-10.3 animal cards currently use remote Wikimedia Commons photography as replaceable visual assets.

These files were selected because their Commons pages identify them as public domain or CC0.

| Animal | Commons file | Status |
| --- | --- | --- |
| Panda | Giant panda animal.jpg | Public domain — U.S. Fish & Wildlife Service |
| Tiger | Tiger panthera tigris.jpg | Public domain — U.S. Fish & Wildlife Service |
| Koala | Koala Phascolarctos cinereus.jpg | CC0 |
| Gorilla | Hiding Gorilla.jpg | CC0 |

The URLs are visual-content placeholders, not Zoo identity data and not evidence that a particular individual animal is currently viewable.

Before offline/PWA packaging, final selected imagery should be bundled locally with source metadata retained.
